# Cartwise

여러 쇼핑몰의 동일·유사 상품 가격을 비교해 수량, 후보별 배송비와 쿠폰을 반영한 가장 저렴한 구매 조합을 찾는 웹 앱입니다.

## 주요 기능

- 상품별 구매 수량 입력
- 쿠팡, 네이버, SSG.COM, 옥션, G마켓, 11번가 등 16개 쇼핑 서비스 선택
- 캡처 붙여넣기·끌어놓기·파일 선택으로 가격 후보 인식
- 인식된 여러 가격 중 사용자가 실제 구매가격 선택
- 항상 무료, 유료, 주문금액 이상 무료, 수량 이상 무료 배송 지원
- 배송비를 쇼핑몰 전체가 아닌 각 구매 후보에 설정
- 정액·정률 쿠폰과 최소 주문금액, 최대 할인금액 지원
- 같은 쇼핑몰에서 조건을 만족하는 쿠폰 중 할인액이 가장 큰 한 장 적용
- 입력 내용을 브라우저에 자동 임시 저장
- 모바일과 PC에서 사용할 수 있는 4단계 입력 화면

## 개인정보와 운영 구조

OCR은 Tesseract.js로 사용자 브라우저 안에서 실행됩니다. 캡처 이미지는 서버나 외부 AI API로 전송되지 않으며 저장되지 않습니다. OCR 실행 파일과 언어 데이터도 사이트에 포함되어 외부 CDN을 요청하지 않습니다.

앱은 로그인, 데이터베이스, API 키와 별도 백엔드를 사용하지 않는 정적 웹사이트로 빌드할 수 있습니다.

## 로컬 실행

Node.js 22 이상과 pnpm이 필요합니다.

```bash
pnpm install
pnpm dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 검증

```bash
pnpm test:optimizer
pnpm lint
pnpm build
```

## 현재 계산 범위

- 한 상품의 요청 수량은 선택된 구매 후보 한 곳에서 모두 구매합니다.
- 후보별 배송비를 한 번씩 계산합니다.
- 같은 판매자의 묶음배송과 여러 후보로 나누어 사는 수량 분할은 지원하지 않습니다.
- 상품 URL 자동 분석, 로그인, 서버 저장과 유료 AI API는 사용하지 않습니다.
