# Cartwise — 장바구니 최적 구매 조합 계산기

여러 쇼핑몰의 동일·유사 상품 후보를 입력하고 상품 판매가, 배송비, 무료배송 조건과 보유 쿠폰을 함께 반영해 전체 결제 금액이 가장 낮은 구매 조합을 찾는 Next.js 웹 앱입니다. 입력 내용은 브라우저 상태에서만 관리하며 데이터베이스를 사용하지 않습니다.

## 주요 기능

- 상품 그룹과 쇼핑몰별 구매 후보를 자유롭게 추가·삭제
- `originalPrice`, `salePrice`, `discountRate`를 분리해 기본 할인 중복 적용 방지
- 쇼핑몰별 기본 배송비, 무료배송 기준, 항상 무료배송 설정
- 정액·정률 쿠폰, 최소 주문금액과 최대 할인금액 지원
- 각 쇼핑몰 주문에 적용 가능한 쿠폰 중 할인액이 가장 큰 한 장 자동 적용
- 쇼핑몰별 상품 목록, 상품 합계, 배송비, 쿠폰 할인, 최종금액과 원본 링크 표시
- 알고리즘을 즉시 확인할 수 있는 3개 쇼핑몰·3개 상품 샘플 데이터
- JSON-LD → 메타/OG → 알려진 가격 selector → 쇼핑몰 전용 parser 순서의 URL 분석
- 자동 분석 실패 시 오류를 격리하고 수동 입력 안내

## 최적화 알고리즘

각 상품마다 후보 하나를 선택해야 하므로 후보 수의 곱만큼 조합이 생깁니다. Cartwise는 백트래킹으로 유효한 선택을 하나씩 만들며 완성된 조합을 정확히 평가합니다. 쇼핑몰 단위로 상품을 묶은 뒤 상품 판매가 합계, 무료배송, 배송비, 가장 유리한 쿠폰 순으로 최종 금액을 계산합니다.

백트래킹을 사용한 이유는 상품마다 후보 수가 달라도 구현이 명확하고, 배송비·쿠폰처럼 상품 사이에 영향을 주는 조건을 정확하게 평가할 수 있기 때문입니다.

가지치기(Branch and Bound)는 현재 선택 금액에 남은 각 상품의 최소 판매가를 더하고, 앞으로 받을 수 있는 쿠폰 할인을 최대한 낙관적으로 뺀 하한을 사용합니다. 이 하한이 이미 발견한 최적 금액 이상이면 해당 가지를 더 탐색하지 않습니다. 배송비는 하한에서 0원으로 가정하므로 최적해를 잘못 제거하지 않습니다.

핵심 코드는 다음처럼 UI와 분리되어 있습니다.

```text
lib/
  optimizer/
    types.ts
    calculateOrder.ts
    optimizer.ts
  scraper/
    index.ts
    generic.ts
    gmarket.ts
    elevenst.ts
```

## 상품 URL 분석과 보안

URL 분석은 사용자가 버튼을 누른 단일 URL만 요청하며 대량 크롤링, CAPTCHA 우회, 로그인 우회, 봇 차단 우회를 하지 않습니다. 사이트가 요청을 거절하거나 자바스크립트 렌더링을 요구하면 실패할 수 있습니다. 현재 범용 JSON-LD/Offer 및 메타 정보를 우선 지원하고, G마켓과 11번가용 보조 parser 구조를 포함합니다. 쇼핑몰 HTML 변경에 따라 전용 parser가 작동하지 않을 수 있으므로 항상 수동 입력을 지원합니다.

API는 http/https만 허용하고 localhost, 사설·링크로컬 IP 리터럴, 내부 호스트명과 사용자정보 포함 URL을 차단합니다. 각 리디렉션도 다시 검증하며 최대 3회, 요청당 8초, HTML 응답 2MB로 제한합니다. 배포 플랫폼의 네트워크 정책도 함께 적용됩니다.

## 실행 방법

Node.js 22.13 이상과 pnpm을 권장합니다.

```bash
pnpm install
pnpm dev
```

`http://localhost:3000`에서 실행됩니다. 최적화 샘플 검증은 `pnpm test:optimizer`, 프로덕션 빌드는 `pnpm build`로 실행합니다.

## Vercel 배포

1. 이 폴더를 GitHub 저장소에 push합니다.
2. Vercel에서 **Add New → Project**를 선택하고 저장소를 연결합니다.
3. Framework Preset이 Next.js인지 확인합니다.
4. 별도 환경변수 없이 Deploy를 누릅니다.

App Router의 Route Handler 하나가 외부 상품 페이지를 요청하므로 정적 내보내기 대신 일반 Next.js 배포를 사용해야 합니다.

## 현재 구현하지 않은 기능

- 로그인, 개인 쇼핑몰 계정 및 쿠폰 자동 연동
- 데이터베이스 저장과 여러 기기 동기화
- 한 주문에 여러 쿠폰 중복 적용
- 옵션·수량·판매자별 묶음배송의 세부 규칙
- 봇 차단 또는 로그인이 필요한 상품 페이지 분석
- 대량 URL 수집 및 정기 크롤링
